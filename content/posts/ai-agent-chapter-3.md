读完了《AI Agent》的第三章，信息量很大，记一下我的理解。

## 核心观点

Agent 不只是"会聊天的 AI"，它是一个能感知环境、做出决策、采取行动的系统。

这和我之前的理解很不一样。我之前觉得 Agent 就是一个更聪明的 Chatbot，但这一章让我意识到，关键区别在于：

1. **自主性**：Agent 能自己决定下一步做什么，而不是等着用户输入
2. **工具使用**：Agent 能调用外部工具和 API，不只是生成文本
3. **记忆**：Agent 有短期和长期记忆，能记住之前的交互

## 让我印象最深的部分

是关于 ReAct 框架的介绍。它把推理（Reasoning）和行动（Acting）结合起来，让 Agent 先思考再行动。

这有点像人类解决问题的方式：先分析问题，制定计划，然后执行，遇到新问题再调整。

## 和我的项目的关系

我之前用 Dify 搭的那个笔记整理助手，其实只是一个简单的工作流，算不上真正的 Agent。因为它不会自主决策，只是按固定流程走。

下一步我想给它加上 ReAct 的能力，让它能根据笔记的内容自动决定用哪种整理策略。

## 一些疑问

- Agent 的"理解"和人类的"理解"到底有什么本质区别？
- 当 Agent 越来越自主，我们如何确保它的行为符合预期？

这些可能是后面几章会讨论的内容，期待。
